🚗⚡ EV Sales Analysis in India

📌 Project Overview

This project presents an end-to-end data analysis of Electric Vehicle (EV) sales in India, combining Python, SQL, Streamlit, and Power BI to deliver insights through interactive dashboards and visualizations. The objective is to analyze EV adoption trends across years, states, and vehicle categories, and present the findings in a professional, industry-ready format.

This repository demonstrates complete data analyst skills — from data cleaning and analysis to dashboard creation and deployment.


---

🎯 Objectives

Analyze year-wise growth of EV sales in India

Compare EV adoption across different states

Understand distribution by vehicle category (2W, 3W, 4W, etc.)

Build interactive dashboards for stakeholders

Showcase practical skills using real-world tools

🔹 Power BI Dashboard

The Power BI report (.pbix) includes:

KPIs: Total EV Sales, Total States, Total Years, Vehicle Types

Line Chart: Year-wise EV sales trend

Bar Chart: Top states by EV sales

Donut Chart: Vehicle category distribution

Slicers: State, Vehicle Category, Year

Custom background and professional color theme


📌 Note: The .pbix file is downloadable and can be opened using Power BI Desktop.
